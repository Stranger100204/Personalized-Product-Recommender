# Personalized Product Recommendation System for E-Commerce

## Overview

A hybrid recommendation system that generates personalized product recommendations using a combination of Content-Based Filtering, Collaborative Filtering, and Popularity-Based Ranking techniques. The system also provides explainable recommendations and an interactive Streamlit dashboard for real-time product discovery.

## Features

* Content-Based Product Recommendations using TF-IDF and Cosine Similarity
* Item-Based Collaborative Filtering using user-product interaction patterns
* Popularity-Based Product Ranking
* Hybrid Recommendation Engine
* Explainable Recommendations
* Interactive Streamlit Dashboard

## Tech Stack

* Python
* Pandas
* Scikit-Learn
* Streamlit
* TF-IDF Vectorization
* Cosine Similarity

## Dataset

E-Commerce Behavior Data from Multi-Category Store

Dataset Attributes:

* User Interactions
* Product Metadata
* Product Categories
* Brands
* Purchase Events

## Recommendation Pipeline

1. Data Preprocessing and Interaction Scoring
2. Product Catalog Generation
3. Content-Based Filtering
4. Collaborative Filtering
5. Popularity-Based Ranking
6. Hybrid Score Generation
7. Explainable Recommendations
8. Streamlit Dashboard
